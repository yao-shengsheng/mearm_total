任务三 · 硬件串口直连版 —— 接线与使用说明
================================================================
生成时间：2026-10-10
适用：按键板 Uno（第二块） + 主控 Uno（叠着 ArmJoystick，驱动机械臂）

----------------------------------------------------------------
一、这次改了什么（和旧版对照）
----------------------------------------------------------------
旧版：两块板之间只有 1 根单向信号线
        按键板 D6 (软串口 TX)  ──>  主控 D10 (软串口 RX)
        程序里用 SoftwareSerial，主控只收不发。

新版：D6 ~ D10 那几根线**全部去掉**，改成两块板的硬件串口 RX/TX 对接
        按键板 TX (D1)  ──>  主控 RX (D0)
        主控 TX (D1)    ──>  按键板 RX (D0)     （可选）
        按键板 GND      ───  主控 GND           （必须）

        程序里直接用 Serial（D0/D1），不再需要 SoftwareSerial。
        好处：少一个库、少一层软件时序；少一根线；两根线就能跑。
        代价：D0/D1 同时也是 USB 口，串口线上"三方共用"，有副作用（见第五节）。


----------------------------------------------------------------
二、接线表（照着接，一共 3 根，最少 2 根）
----------------------------------------------------------------
【按键板那一侧】
  1) 按键 1 的一个脚  ->  D2
  2) 按键 2 的一个脚  ->  D3
  3) 按键 3 的一个脚  ->  D4
  4) 按键 4 的一个脚  ->  D5
  5) 每个按键的**另一个脚** -> 面包板 GND 总线     <- 最常见的错：漏了这一步
  6) 面包板 GND 总线  ->  按键板 GND 引脚
     （程序用了芯片内部上拉，不用加电阻）

【两块板之间】★ 只有这部分和旧版不同
  7) 按键板 TX (D1)   ->  主控 RX (D0)     必须接
  8) 按键板 GND       <-> 主控 GND         必须接，不接必乱码
  9) 主控 TX (D1)     ->  按键板 RX (D0)   ★ 可选，接不接都能跑

     第 9 根接上的好处：主控的打印会顺着线流回按键板，
                        开一个串口监视器就能同时看两边。
     第 9 根不接的理由：烧录按键板时它必须拔掉（见第五节 ②），
                        不接就省了拔插这一步。推荐干脆不接。

【USB 线】两块板各插一个 USB 口，只用来供电和数据观察。


----------------------------------------------------------------
三、三个程序分别是什么，该烧哪个
----------------------------------------------------------------
文件位置                              烧到哪块板    用途
------------------------------------  ------------  ------------------------------
uno_keys_basic\uno_keys_basic.ino     按键板        ★精简版，只有按键 1/2/3/4 功能
uno_keys_check\uno_keys_check.ino     按键板        带接线自检/电平监视等排查工具
task3_main_hwserial\                  主控          配套主控程序，输入改用硬件串口
  task3_main_hwserial.ino

【怎么选】
  · 需要排查接线 -> 烧 uno_keys_check.ino
  · 接线已经好了、要上台演示 -> 烧 uno_keys_basic.ino（最干净，不会刷屏）
  · 主控必须换 task3_main_hwserial.ino，否则收不到按键板发来的字符
    （旧版主控读的是 D10 软串口）。旧文件 task3_arduino.ino 没有改动，保留着。

★ 检查版的命令（在按键板自己的串口监视器里，9600，敲字母回车）：
    t  ->  按键接线自检，一步步提示你按每个键，最后给"通过 n / 4"
    w  ->  实时电平监视 开/关（按住键，看它到底接在哪个 D 号上）
    s  ->  联机测试：往主控发 5 个 '?'，主控应回 5 行 +LINK OK
    i  ->  再看一遍 4 个引脚的静态电平
    h  ->  命令列表
    q  ->  自检进行中发 q 可中断


----------------------------------------------------------------
四、推荐操作顺序（这样最不容易乱）
----------------------------------------------------------------
第一步 · 只插按键板 USB，先别接第 7/8/9 根线
    烧 uno_keys_check.ino -> 发 t 做自检 -> 4 个键全 PASS 再往下走。
    （此时 RX 上没有任何干扰，自检提示最干净、不会刷屏。）

第二步 · 烧主控
    烧 task3_main_hwserial.ino，打开主控的串口监视器（9600）。
    先不接按键板，直接在监视器里敲 1 / 2 / 3 / 4，把整条动作流程走一遍。

第三步 · 接第 7、8 根线（TX->RX + 共地），插上按键板
    在按键板串口里发 s 做联机测试 -> 主控应出现 5 行 +LINK OK。
    一行都没有 = 这两根线的问题，跟按键无关，故障范围一步砍半。

第四步 · 按真按键
    主控应出现  +key: 1  然后执行动作。
    是乱码 -> 没共地或波特率不一致；没反应 -> 先看 TX/RX 有没有接反。


----------------------------------------------------------------
五、必须知道的三个坑（硬件串口直连的固有特点，不是程序 bug）
----------------------------------------------------------------
① D0/D1 也是 USB 口，串口线上"三方共用"：
      · 在主控监视器里敲 '1' -> 机械臂会动（这是好事，方便单独测）
      · 在按键板监视器里敲 '1' -> 机械臂**也会动**
        （那根线同样接在主控的 RX 上）
      · 按键板打印的调试文字会流进主控，主控当成未知指令，
        回一大堆 "Unknown Command" —— 看着花，完全无害
   结论：演示时只看**主控**那一个串口监视器，最清楚。

② 烧录按键板之前，把"主控 TX -> 按键板 RX"（第 9 根）拔掉，或给主控断电。
   因为主控的 TX 是强输出，一直把按键板的 RX 顶住，
   会和 USB 串口芯片抢同一条线 -> 烧录失败 / 校验出错。
   ★ 只接第 7、8 根就没有这个问题。主控那头再烧录就不受影响。

③ 别把 TX/RX 接成"同名对同名"：
   一定是**交叉**接 —— 按键板 TX 去主控 RX，主控 TX 去按键板 RX。
   接成 TX-TX 两根强输出对顶，两边都不通，还可能发热。


----------------------------------------------------------------
六、常见故障速查
----------------------------------------------------------------
现象                        最可能的原因
--------------------------  ----------------------------------------
主控收到的一直是乱码        没共地（第 8 根），或两边波特率不一致
按任何键都没反应            忘共地 / TX-RX 接反 / 第 7 根松了
主控收到大量 Unknown        正常现象，那是按键板的调试文字，忽略
按键板烧录失败              第 9 根没拔（见第五节 ②）
自检报某个键 FAIL           那个键的另一脚没接 GND（最常见），
                            或面包板那一列内部不通，或线插错 D 号
                            用 w 实时监视，看它真正接在哪个 D 号上
按一次键动了两次            消抖时间不够（把 KEY_DEBOUNCE 调大），
                            或按键本身接触不良
刚上电机械臂自己就动        某个键引脚被直接短到 GND（按键常闭/接错），
                            上电自检会把它标成"异常！"


----------------------------------------------------------------
七、和旧版文件的关系
----------------------------------------------------------------
· task3_arduino.ino（主控，软串口 D10 版）—— 原文件保留未动，
  它是"按键板 D6 → 主控 D10 单向软串口"的版本，和本版接线不同，
  要用哪个版本就烧对应的那一个。
· uno_keys.ino、uno_keys_key5.ino（旧按键板）—— 也保留未动，
  它们是"发到 D6"的版本，和现在的接线不匹配，不要混烧。
